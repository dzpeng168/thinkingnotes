## R — 风险 · Risk

> 开头先说不采纳你的建议会带来什么风险（人在失去时比获得时更敏感）。
>
> 适当放大风险，但不要过于夸张。

**不采纳建议的风险**：

| 风险点 | 影响程度 | 发生概率 | 说明 |
|---|---|---|---|
| 1.  | 🔴 高 / 🟡 中 / 🟢 低 | 🔴 高 / 🟡 中 / 🟢 低 |  |
| 2.  | 🔴 高 / 🟡 中 / 🟢 低 | 🔴 高 / 🟡 中 / 🟢 低 |  |
| 3.  | 🔴 高 / 🟡 中 / 🟢 低 | 🔴 高 / 🟡 中 / 🟢 低 |  |

**开场话术参考**：
> 如果我们不这样做，可能会面临……

**注意事项**：
- [ ] 风险要真实存在，不要危言耸听
- [ ] 适当放大，但不过于夸张
- [ ] 与对方的利益直接相关

---

## I — 利益 · Interest

> 接受你的建议会带来什么利益（前面降低了心理阈值，这一步更容易接受）。
>
> 切勿把好处说的过于肯定，让对方有个对比即可。

**采纳建议的利益**：

| 利益点 | 价值 | 见效时间 | 说明 |
|---|---|---|---|
| 1.  | 🔴 高 / 🟡 中 / 🟢 低 | 短期 / 中期 / 长期 |  |
| 2.  | 🔴 高 / 🟡 中 / 🟢 低 | 短期 / 中期 / 长期 |  |
| 3.  | 🔴 高 / 🟡 中 / 🟢 低 | 短期 / 中期 / 长期 |  |

**承接话术参考**：
> 相比之下，如果我们采纳这个方案，可以……

**注意事项**：
- [ ] 好处要具体，不要空泛
- [ ] 不说得过于肯定，留有余地
- [ ] 与前面的风险形成鲜明对比

> 你的不同之处需要和对方相关，而不是自嗨的与众不同。

- [ ] 突出独特性，但不贬低其他方案

## E — 影响 · Effect

> 适当说一下你建议的瑕疵，增加可信度（太完美的东西反而不真实，有点小缺点但瑕不掩瑜）。
>
> 不要谦虚过头，找出一大堆问题，最终起到反面效果。

> 当然，这个方案也不是完美的，它在……方面还有一些不足，但整体来说……

**注意事项**：
- [ ] 只提小瑕疵，瑕不掩瑜
- [ ] 不要谦虚过头，列出一堆问题
- [ ] 每个瑕疵都要有对应的应对思路

## 💡 使用技巧

**说服顺序很重要**：
```
风险（损失厌恶）→ 利益（收益对比）→ 差异（独特吸引）→ 影响（坦诚可信）
```

**适用场景**：
- 向上级提方案建议
- 向客户推销产品/服务
- 跨部门协调争取资源
- 说服同事接受你的想法

**关键原则**：
1. **先失后得** — 先说风险再说利益，利用损失厌恶心理
2. **对比鲜明** — 风险和利益形成强烈对比
3. **突出独特** — 人无我有，人有我优
4. **适度自黑** — 主动提小缺点，增加可信度
5. **交还决策** — 说服不是逼迫，给对方选择权
