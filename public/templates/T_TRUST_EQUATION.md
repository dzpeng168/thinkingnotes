# 麦肯锡信任公式

> **信任 = (C 可信度 + R 可靠度 + I 亲密度) / S 自私度**
>
> 出自《值得信赖的顾问》（The Trusted Advisor），麦肯锡顾问的经典信任评估模型：分子越大信任越高，分母（自私度）越大信任被稀释得越厉害。

**评估对象**：（这段信任关系是关于谁？如：直属领导 / 客户 / 合作伙伴 / 伴侣）

---

## 🎯 可信度 C（Credibility — 你说的话可信吗）

**加分项**

- [ ] 有拿得出手的高质量成果
- [ ] 有权威证书 / 口碑背书
- [ ] 能看清复杂问题的本质
- [ ] 给的反馈有建设性
- [ ] 能解决复杂问题

**减分项**

- [ ] 专业储备不足
- [ ] 缺乏独立思考
- [ ] 不懂装懂
- [ ] 只批评、不给建议

## ⏰ 可靠度 R（Reliability — 你做的事靠谱吗）

**加分项**

- [ ] 信守承诺，说到做到
- [ ] 守时，不迟到
- [ ] 不轻易承诺
- [ ] 做事有条理
- [ ] 压力下保持冷静

**减分项**

- [ ] 经常逾期交付
- [ ] 质量妥协
- [ ] 优先做紧急但不重要的事
- [ ] 重复犯同样的错误

## 💞 亲密度 I（Intimacy — 你与TA的距离）

**加分项**

- [ ] 高频互动
- [ ] 有共同兴趣 / 价值观
- [ ] 主动关注对方
- [ ] 了解对方的细节
- [ ] 共过患难

**减分项**

- [ ] 没有工作之外的交集
- [ ] 彼此不了解
- [ ] 没有深度沟通
- [ ] 对方不了解你的信息

## 🪞 自私度 S（Self-orientation — 分母，越低越好）

> S 在分母上：越以自我为中心，信任被稀释得越厉害。

**降低 S 的行为（加分）**

- [ ] 直面问题，不回避
- [ ] 出问题先找解决方案，不找借口
- [ ] 功劳分享、责任共担
- [ ] 合作心态

**推高 S 的行为（警惕）**

- [ ] 回避问题
- [ ] 找借口
- [ ] 抢功甩锅
- [ ] 以自我为中心
