## 🔵 别人做 · Delegate it

> **可以授权或委派给他人替你完成的工作**
>
> 通过授权、委派，给自己腾出更多时间，处理重要的事。
>
> *例如：安排下属去出席一个不重要的论坛；寻求老板的帮助，解决一个超出你职责范围的审批。*

- [x] 这件事别人也能做（至少 80% 效果）

- [x] 委派后有明确的验收标准

## 🟢 马上做 · Do it now

> **2 分钟可以完成的事情**
>
> 两三分钟能完成的事，马上做掉，避免这些事项的存在占用大脑内存。
>
> *例如：给财务发一份表格；给供应商发一封确认邮件；随手给新添加的好友写好备注。*

- [x] 回复老板"收到，马上处理"的微信
- [x] 给客户发送项目进度截图
- [x] 把今天的会议链接添加到日历
- [x] 给新添加的候选人备注姓名+岗位
- [x] 清空邮箱垃圾邮件
- [x] 回复同事关于文档位置的询问
- [ ] 给花浇水
- [ ] 整理桌面散落的文件

**判断标准**：
- [x] 预计耗时 ≤ 2 分钟
- [x] 不需要额外准备或资源
- [x] 做完就能彻底划掉

## 🟡 待会做 · Defer it

> **无法委派、2 分钟也做不完的事情**
>
> 没有办法马上做、需要大块时间处理，也无法委派出去的工作，写下来，放进待办清单。写下来，是为了暂时忘记，让大脑专注于眼前的工作，待完成当前工作，再从待办清单中拿取新工作。

## 🔴 不要做 · Delete it

> **无法委派、2 分钟做不完、没必要做的事情**
>
> 这些事，果断放弃、删除。不要让你的脑子被琐事占领，而是清空它们。
>
> *比如：某个无关紧要的会议；某个无足轻重的邮件。*

| 已删除的事项 | 删除原因 | 备注 |
|---|---|---|
| 参加跨部门团建的讨论会议 | 价值太低 / 不相关 | 已有同事代表参加，与我工作无关 |
| 帮其他部门整理报销单据 | 价值太低 / 可跳过 | 不在我的职责范围内，可礼貌拒绝 |
| 刷半小时行业新闻公众号 | 价值太低 | 信息过载，每天 10 分钟足够 |
| 回复群里"收到"刷屏消息 | 价值太低 / 可跳过 | 不影响工作，已读即可 |
| 研究一个用不上的新工具 | 不相关 | 当前阶段不需要，以后需要再研究 |

**判断标准**：
- [x] 做了也不会带来明显价值
- [x] 不做也不会产生负面影响
- [x] 属于可以拒绝/忽略的琐事
