# 时间管理四象限

## 第一象限 · 重要 + 紧急

**行动策略：马上做**

- [x] 修复线上支付 Bug（用户无法付款）
- [x] 客户紧急需求变更（明天上线）
- [ ] 明天项目评审的 PPT 还没做完
- [ ] 服务器告警，CPU 占用 90%
- [ ] 老板下午要季度数据，还没整理

**典型特征：** 危机 / 紧迫 / 截止日期

**现状：** 5 件，太多了，要想办法减少

---

## 第二象限 · 重要 + 不紧急

**行动策略：计划做**

- [x] 制定 Q4 产品规划
- [ ] 梳理用户成长体系
- [ ] 团队技术分享准备
- [ ] 读一本产品设计的书
- [ ] 健身计划（每周 3 次）
- [ ] 和团队成员 1-on-1 沟通

**典型特征：** 成长 / 规划 / 预防措施

**现状：** 6 件，这是最重要的象限，应该多投入时间

---

## 第三象限 · 不重要 + 紧急

**行动策略：委托做**

- [x] 委托给：实习生整理竞品功能表
- [x] 委托给：行政帮订团队聚餐的餐厅
- [ ] 委托给：数据分析师出上周数据周报
- [ ] 委托给：HR 安排新员工入职手续

**典型特征：** 干扰 / 会议 / 重复性事务

**现状：** 4 件，尽量委托出去，别占用自己的时间

---

## 第四象限 · 不重要 + 不紧急

**行动策略：不要做**

- [x] 刷了半小时朋友圈
- [x] 回复群里"收到"刷屏消息
- [ ] 看了一个无关的行业八卦文章
- [ ] 研究一个暂时用不上的新工具
- [ ] 整理桌面图标（其实不需要）

**典型特征：** 琐事 / 刷手机 / 逃避行为

**现状：** 5 件，果断砍掉，别让这些事偷走你的时间

---

### 四象限分析说明

**第一象限（重要+紧急）现状反思**：
- 目前有 5 件事在第一象限，说明平时第二象限投入不够，很多事情被逼成了紧急
- 目标：把第一象限的事控制在 2-3 件以内

**第二象限（重要+不紧急）行动规划**：
- 这是"个人成长"象限，投入越多，第一象限的事就越少
- 本周计划：每天至少投入 1 小时在第二象限

**第三象限（不重要+紧急）委托策略**：
- 能委托的尽量委托，节省时间给第一、二象限
- 委托后要跟进结果，不能完全撒手

**第四象限（不重要+不紧急）断舍离**：
- 每天刷手机时间控制在 30 分钟以内
- 用番茄钟提醒自己，避免无意识刷手机

---

### 本周时间分配目标

| 象限 | 理想占比 | 当前估计 | 目标 |
|---|---|---|---|
| 第一象限（马上做） | 20-25% | 40% | 降到 25% |
| 第二象限（计划做） | 65-80% | 30% | 升到 60% |
| 第三象限（委托做） | 5-10% | 15% | 降到 10% |
| 第四象限（不要做） | <1% | 15% | 降到 5% |
