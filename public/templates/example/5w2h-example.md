## 二、Why — 为什么 ❓

> 为什么要做？原因是什么？背后的动机和目的是什么？

| 维度 | 分析 |
|---|---|
| **根本原因** | 年度总结与团队建设的传统，增强员工归属感和凝聚力 |
| **重要性** | 今年公司业绩增长 30%，需要一场成功的年会来肯定大家的付出；同时上海分公司成立一周年，促进两地融合 |
| **不做的后果** | 员工士气下降、归属感降低；新加入的上海团队缺乏融入感；不符合公司文化传统 |
| **替代方案对比** | ① 纯线下年会（传统模式，参与感强但成本高）② 线上+线下结合（节省差旅但体验打折扣）③ 取消年会发红包（成本最低但无凝聚力效果） |

**动机清单**：
- [x] 年度总结与表彰
- [x] 增强团队凝聚力
- [x] 促进北京-上海两地团队融合
- [x] 感谢员工一年的付出
