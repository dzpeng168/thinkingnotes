# 测一测：我与直属领导的信任度

> **信任 = (C 可信度 + R 可靠度 + I 亲密度) / S 自私度**
>
> 出自《值得信赖的顾问》（The Trusted Advisor）。以下是我与直属领导张经理共事一年后的自评，逐项勾选，用公式看清这段信任关系的真实水位。

**评估对象**：直属领导 · 张经理（共事 1 年 2 个月）

---

## 🎯 可信度 C（我说的话可信吗）

**加分项**

- [x] 有拿得出手的高质量成果（Q2 增长复盘报告被总监点名引用）
- [x] 给的反馈有建设性
- [ ] 有权威证书 / 口碑背书
- [ ] 能看清复杂问题的本质
- [ ] 能解决复杂问题

**减分项**

- [x] 专业储备不足（跨到增长领域后，专业深度确实不够）
- [ ] 缺乏独立思考
- [ ] 不懂装懂
- [x] 只批评、不给建议（评审同事方案时偶尔只挑毛病）

## ⏰ 可靠度 R（我做的事靠谱吗）

**加分项**

- [x] 信守承诺，说到做到
- [x] 做事有条理
- [ ] 守时，不迟到（周会迟到了两次…）
- [x] 不轻易承诺
- [x] 压力下保持冷静

**减分项**

- [x] 经常逾期交付（数据看板连续两周压线）
- [ ] 质量妥协
- [x] 优先做紧急但不重要的事（总被救火事项打断节奏）
- [ ] 重复犯同样的错误

## 💞 亲密度 I（我与TA的距离）

**加分项**

- [x] 高频互动（每周 1v1）
- [x] 了解对方的细节（知道他最在意数据严谨性）
- [ ] 有共同兴趣 / 价值观
- [x] 主动关注对方
- [ ] 共过患难（还没一起扛过大事故）

**减分项**

- [x] 没有工作之外的交集（私交基本为零）
- [ ] 彼此不了解
- [x] 没有深度沟通（从未聊过职业规划这类深度话题）
- [ ] 对方不了解你的信息

## 🪞 自私度 S（我够不够"利他"）

**降低 S 的行为（加分）**

- [x] 直面问题，不回避
- [x] 功劳分享、责任共担
- [ ] 出问题先找解决方案，不找借口（上次延期先解释了客观原因）
- [ ] 合作心态

**推高 S 的行为（警惕）**

- [ ] 回避问题
- [x] 找借口（有，见上）
- [ ] 抢功甩锅
- [ ] 以自我为中心

---

## 📊 结论与行动

- **当前信任度评估**：中等偏上。C 和 R 的基础盘是稳的，但 I 和 S 拉低了整体水位——公式的直觉就在这里：分子再大，分母一大，信任照样被稀释。
- **最需要补强的要素**：I（亲密度）。每周 1v1 只谈业务，从没聊过成长诉求；同时 S 侧要戒掉"先解释再解决"的惯性。
- **下一步行动**：
  1. 下周 1v1 主动请教一次职业发展建议，打开一次深度沟通；
  2. 交付节奏改为"周三过半同步"，用透明治好逾期；
  3. 下次评审先给替代方案，再谈问题。
