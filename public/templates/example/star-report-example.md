# 「极速发票」项目汇报

> **STAR · 用手做事，用嘴做成事。**
> S 背景 → T 任务 → A 行动 → R 结果，用 5 分钟讲清一个 3 个月的项目。

**汇报对象**：事业部季度评审会

---

## ① S · 背景 Situation

> 当时为什么做这个项目…

- 去年 Q3 起客服收到大量投诉：电子发票开票平均等待 3.2 天，财务每月有 4 天人力被开票占满。
- 运营测算：开票慢是续费流失的第 2 大归因，估算年化影响约 180 万营收。

## ② T · 任务 Task

> 当时设定的任务目标是什么…

- 我作为项目 PM，目标：**90 天内把开票时效从 3.2 天压到 0.5 天内（自动化率 ≥85%）**。
- 为什么是这个目标：0.5 天是用户无感知的阈值，85% 自动化率是财务人效翻倍的最低要求。

## ③ A · 行动 Action

> 我 / 团队做了哪些具体工作…

- 拆解开票链路 11 个环节，定位 3 个卡点：税控系统手工触发、抬头信息人工校验、月度批量排队。
- 我主导的方案：接入税务服务商 API 自动开票 + OCR 自动校验抬头 + 队列削峰。
- 最大的难题：财务担心自动开票的合规风险。我的解法是先跑 30 天"自动开票 + 人工抽检 10%"的影子模式，用 0 差错数据换来财务签字放行。

## ④ R · 结果 Result

> 项目有什么成果…

- 开票时效：**3.2 天 → 4 小时**（超预期，目标 0.5 天），自动化率 91%。
- 财务每月节省 3 个人日，开票相关投诉下降 92%。
- 复盘经验可迁移：**"影子模式"方法论**——任何涉及合规/风控的自动化，先并行跑、用数据换信任，再切换。已沉淀为部门 SOP。

---

## 📢 一句话汇报（电梯版）

> 客户等发票要 3 天，我们 90 天把它压到 4 小时、自动化 91%，财务人效翻倍——秘诀是让自动系统先"陪跑"一个月，拿零差错数据说服了财务。
