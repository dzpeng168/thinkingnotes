## 🟢 Do it now

> **Things that can be done in 2 minutes**
>
> Handle 2-3 minute tasks right away to prevent them from occupying your mental space.
>
> *Example: Send a spreadsheet to finance; send a confirmation email to a supplier; add a note for a newly added contact.*

- [x] Reply to boss's WeChat "Got it, handling immediately"
- [x] Send project progress screenshot to client
- [x] Add today's meeting link to calendar
- [x] Note name + position for newly added candidate
- [x] Clear junk email
- [x] Reply to colleague's question about document location
- [ ] Water the plants
- [ ] Organize scattered files on desktop

**Decision criteria**:
- [x] Estimated time ≤ 2 minutes
- [x] No extra preparation or resources needed
- [x] Can be completely crossed off when done

## 🟡 Defer it

> **Things that cannot be delegated and take more than 2 minutes**
>
> Work that can't be done right away, requires block time, and cannot be delegated—write it down and put it in the todo list. Writing it down allows you to temporarily forget it, so your brain can focus on the task at hand.

## 🔴 Delete it

> **Cannot delegate, takes over 2 minutes, and unnecessary**
>
> Abandon and delete these decisively. Don't let trivial things occupy your mind—clear them out.
>
> *Example: An irrelevant meeting; an insignificant email.*

| Deleted item | Reason for deletion | Notes |
|---|---|---|
| Attend cross-department team building discussion | Too low value / Irrelevant | A colleague is already attending; unrelated to my work |
| Help another department organize expense reports | Too low value / Skippable | Outside my responsibilities; can politely decline |
| Scroll industry news WeChat accounts for 30 min | Too low value | Information overload; 10 min/day is enough |
| Reply to "Got it" flood messages in group chat | Too low value / Skippable | Doesn't affect work; mark as read is fine |
| Research a new tool that won't be used | Irrelevant | Not needed at current stage; revisit later if needed |

**Decision criteria**:
- [x] Doing it brings no significant value
- [x] Not doing it causes no negative impact
- [x] Trivial tasks that can be refused / ignored
