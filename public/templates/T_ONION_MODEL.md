# 洋葱模型

> **洞察人心本质：剥洋葱。**
> 从最外层的"行为"到最深处的"自我"，共 8 层。看看你对一个人的洞察，能剥到第几层？

**洞察对象**：（想分析谁？如：同事小王 / 客户刘总 / 合作伙伴）

---

## 第 1 层 · 行为 / 事件

> 能客观描述所发生的事情

- 对方做了什么、说了什么：
- 我观察到的具体事件（不评价、不解读）：

## 第 2 层 · 应对方式

> 能识别对方的应对模式 / 姿态

- 对方习惯的应对姿态（指责 / 讨好 / 超理智 / 打岔 / 顺从 / 回避…）：
- 面对压力时的惯性模式：

## 第 3 层 · 情绪 / 感受

> 能捕捉到对方精准的情绪

- 对方的情绪是什么（准确命名：委屈 / 失落 / 焦虑 / 愤怒 / 无力…）：
- 为什么会有这种情绪：

## 第 4 层 · 感受的感受

> 能共情对方更深层次的感受

- 对这个情绪本身的感受（如：对愤怒感到内疚、为难过而羞耻…）：

## 第 5 层 · 想法 / 信念

> 能直指对方的内在观点

- 对方如何看待这件事（看事情的视角）：
- 对方的信念 / 假设 / "滤镜"（正是这些滤镜，才产生了第 3、4 层的感受和情绪）：

## 第 6 层 · 期待

> 能洞悉对方的期待

- 对自己有什么期待：
- 对别人（包括我）有什么期待：
- 对事情的发展有什么期待：

## 第 7 层 · 渴望

> 能共鸣对方内心深处的需求 / 渴望

- 人类共有的底层需求（被爱 / 被认可 / 被尊重 / 被接纳 / 价值感 / 安全感 / 自由…）：
- 对方真正渴望的是：

## 第 8 层 · 自我

> 能洞穿对方的自我

- 对方如何看待自己：
- 对方如何成为今天的自己（经历与塑造）：
- 对方的生活意义和人生使命：
