# STAR 项目汇报

> **用手做事，用嘴做成事。**
> S 背景 → T 任务 → A 行动 → R 结果，把项目讲成一条清晰的时间线。

**汇报对象**：（如：总监 / 项目评审会 / 客户）

---

## ① S · 背景 Situation

> 当时为什么做这个项目…

- 项目启动的缘由（业务痛点 / 上级要求 / 市场机会）：
- 是为了解决什么问题：

## ② T · 任务 Task

> 当时设定的任务目标是什么…

- 我的角色与职责：
- 目标（尽量可量化）：
- 为什么设定这些目标：

## ③ A · 行动 Action

> 我 / 团队做了哪些具体工作…

- 关键行动（做了什么、怎么做的）：
- 遇到什么难题，如何解决：
- 我的独特贡献（区别于团队其他人的部分）：

## ④ R · 结果 Result

> 项目有什么成果…

- 成果（数据说话：指标提升 / 成本节省 / 按期交付…）：
- 超出预期的部分：
- 复盘经验（可以迁移到未来类似项目）：
