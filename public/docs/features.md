# ThinkingNotes 功能说明

ThinkingNotes 是一款专为“想清楚、记下来、做到位”而设计的思维笔记工具。围绕 15 套经典思维模型，把笔记、日历、复盘、待办整合到同一个工作台，让每一条想法都能被有序地整理、追溯和落地。

---

## 核心能力

### 1. 15 套思维模型模板
开箱即用 15 套结构化模板，覆盖工作、生活、复盘、决策、创造、沟通、目标等高频场景：

| 模板 | 适用场景 |
|---|---|
| 自由笔记 | 从空白开始，自由编写 Markdown |
| 康奈尔笔记 | 课堂学习、读书摘录、知识整理 |
| 5W2H 分析法 | 项目立项、需求梳理、问题拆解 |
| 六顶思考帽 | 团队讨论、决策评审、平行思考 |
| 时间管理四象限 | 任务优先级、每日 / 每周排程 |
| 月计划 | 月度目标、里程碑、关键成果 |
| 周计划 | 本周任务拆解与节奏安排 |
| 日计划 | 今日待办与时间块管理 |
| WOOP 思考法 | 目标驱动、心理对照、行动落地 |
| RIDE 说服法 | 方案评审、利弊分析、向上汇报 |
| PREP 表达法 | 结论先行、结构化表达、汇报答辩 |
| 4D 工作法 | 任务处理流程：删除 / 委托 / 推迟 / 做 |
| 移情图 | 用户访谈、产品定位、需求洞察 |
| SMART 目标 | 目标制定、绩效对齐、OKR 辅助 |
| GRAI 复盘 | 项目回顾、过程复盘、经验沉淀 |

每一套模板都内置了引导问题、占位结构和填写示例，新建即可使用。

### 2. 原生 Markdown 编辑体验
- 基于 Milkdown 引擎，编辑即所见，**所见即所得**
- 支持 GFM：表格、任务列表、删除线、代码块、引用块
- 一键切换 **编辑 / 预览 / 分屏 / 源码** 四种模式
- 支持 Markdown 快捷语法：标题、加粗、斜体、链接、列表、引用等
- 粘贴 HTML / Markdown 自动识别并格式化

### 3. 多端云端同步
- 基于 Supabase 构建，数据云端实时同步
- 网页端登录即可访问全部笔记
- 多人多设备无缝衔接，编辑状态实时保存

### 4. 分类 / 标签 / 收藏
- 支持多级分类（父子结构），按工作、生活、复盘等组织笔记
- 自由打标签，支持标签筛选
- 收藏重要笔记，列表页一键查看

### 5. 日历视图
- 提供日历视图，按日期浏览笔记
- 复盘 / 日计划 / 周计划 模板与日历深度结合

### 6. 中英文双语
- 界面一键切换中文 / 英文
- 模板与示例笔记提供双语言版本
- 适合跨境团队、英文学习、原版阅读等场景

### 7. 游客模式
- 无需注册即可体验所有模板与示例
- 注册后内容可平滑迁移到账号

### 8. 搜索与筛选
- 顶部搜索框支持标题与正文模糊搜索
- 按分类、标签、模板类型快速筛选

### 9. 回收站
- 误删笔记可在回收站恢复
- 回收站二次确认清空，避免误操作

### 10. 主题与外观
- 支持 “极简” 与 “商务” 两种主题风格
- 圆角卡片 + 柔和配色，长时间书写不疲劳

## 适用人群

- **产品 / 运营 / 设计**：5W2H、移情图、RIDE、PREP 帮你结构化思考
- **研发 / 项目经理**：六顶思考帽、四象限、4D、GRAI 让协作更高效
- **学生 / 终身学习者**：康奈尔、SMART、WOOP 让学习和目标更扎实
- **团队 Leader**：月 / 周 / 日计划 + 复盘模板，把节奏装进笔记

---

## 数据安全

- 笔记数据存放在 Supabase 托管数据库
- 登录与认证基于邮箱 + 密码，使用 Supabase Auth 加固
- 回收站机制防止误删，关键操作二次确认
