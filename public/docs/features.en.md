# ThinkingNotes — Features

ThinkingNotes is a thought-note tool built for *think clearly, record well, and execute effectively*. Around 15 classic thinking-model templates, it integrates notes, calendar, review, and to-do into a single workspace so every idea can be organized, traced, and acted on.

---

## Core Capabilities

### 1. 15 Thinking-Model Templates
Out-of-the-box structured templates covering work, life, review, decision-making, creativity, communication, goals, and more:

| Template | Use Case |
|---|---|
| Free Note | Start from blank; write Markdown freely |
| Cornell Notes | Classroom learning, reading notes, knowledge organization |
| 5W2H Analysis | Project kick-off, requirements analysis, problem breakdown |
| Six Thinking Hats | Team discussions, decision reviews, parallel thinking |
| Time Management Quadrants | Task prioritization; daily / weekly scheduling |
| Monthly Plan | Monthly goals, milestones, key results |
| Weekly Plan | This week's task decomposition and pacing |
| Daily Plan | Today's to-dos and time-block management |
| WOOP | Goal-driven, mental contrast, action landing |
| RIDE Persuasion | Option review, pros/cons analysis, upward reporting |
| PREP Expression | Conclusion-first, structured expression, presentations |
| 4D Method | Task processing workflow: Delete / Delegate / Defer / Do |
| Empathy Map | User interviews, product positioning, requirement insights |
| SMART Goals | Goal setting, performance alignment, OKR support |
| GRAI Review | Project retrospective, process review, experience consolidation |

Each template comes with guiding questions, placeholders, and fill-in examples. Click and start writing.

### 2. Native Markdown Editing Experience
- Built on the Milkdown engine; WYSIWYG editing
- GFM support: tables, task lists, strikethrough, code blocks, blockquotes
- Switch instantly between **Edit / Preview / Split / Source** modes
- Markdown shortcut syntax: headings, bold, italic, links, lists, blockquotes
- Paste HTML / Markdown and it auto-detects and formats

### 3. Multi-device Cloud Sync
- Powered by Supabase, data syncs in real time across the cloud
- Log in on any device and access all your notes
- Cross-device seamless experience with auto-save

### 4. Folders · Tags · Favorites
- Multi-level folder support (parent / child structure) — organize by Work, Life, Review, etc.
- Free-form tagging with tag-based filtering
- Star important notes; view them at a glance in the Favorites list

### 5. Calendar View
- Calendar view to browse notes by date
- Deep integration between review / daily / weekly plan templates and the calendar

### 6. Bilingual (Chinese & English)
- One-click switch between Chinese and English interfaces
- Templates and example notes are provided in both languages
- Suitable for cross-border teams, English learning, and native-language reading

### 7. Guest Mode
- No registration required — try every template and example
- Registered content migrates seamlessly to your account

### 8. Search & Filter
- Top search bar supports fuzzy search across titles and body text
- Quick filter by folder, tag, or template type

### 9. Trash & Recovery
- Accidentally deleted notes can be restored from the Trash
- Double confirmation before permanent deletion prevents mistakes

### 10. Themes & Appearance
- Two theme styles: **Minimal** and **Business**
- Rounded cards + soft color palette — comfortable for long writing sessions

---

## Who Is It For

- **Product / Operations / Designers** — 5W2H, Empathy Map, RIDE, PREP help structure thinking
- **Engineers / Project Managers** — Six Thinking Hats, Time Quadrants, 4D, GRAI make collaboration more efficient
- **Students / Lifelong Learners** — Cornell, SMART, WOOP solidify learning and goal-setting
- **Team Leads** — Monthly / Weekly / Daily plans + Review templates to keep the rhythm under control

---

## Data Security

- Note data is stored in Supabase-hosted databases
- Authentication uses email + password, hardened by Supabase Auth
- Trash mechanism prevents accidental deletion; critical operations require double confirmation
