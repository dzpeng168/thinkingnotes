# ThinkingNotes — 功能说明

ThinkingNotes 是一款为「想清楚、记下来、做到位」而设计的思考笔记工具。围绕 15 套经典思维模型模板，把笔记、日历、复盘与待办整合在同一个工作区里，让每个想法都能被整理、被追溯、被执行。

---

## 核心能力

### 1. 15 套思维模型模板
开箱即用的结构化模板，覆盖工作、生活、复盘、决策、创意、沟通、目标等场景：

| 模板 | 适用场景 |
|---|---|
| 自由笔记 | 从空白开始，自由书写 Markdown |
| 康奈尔笔记 | 课堂学习、读书笔记、知识整理 |
| 5W2H 分析 | 项目立项、需求分析、问题拆解 |
| 六顶思考帽 | 团队讨论、决策评审、平行思维 |
| 时间管理四象限 | 任务优先级判断，日 / 周计划排布 |
| 月度计划 | 月度目标、里程碑、关键结果 |
| 周计划 | 本周任务拆解与节奏把控 |
| 每日计划 | 今日待办与时间块管理 |
| WOOP | 目标驱动、心理比对、行动落地 |
| RIDE 说服 | 方案评审、利弊分析、向上汇报 |
| PREP 表达 | 结论先行、结构化表达、汇报演讲 |
| 4D 工作法 | 任务处理流程：删除 / 委派 / 推迟 / 执行 |
| 同理心地图 | 用户访谈、产品定位、需求洞察 |
| SMART 目标 | 目标设定、绩效对齐、OKR 支撑 |
| GRAI 复盘 | 项目回顾、流程复盘、经验沉淀 |

每个模板都内置引导问题、占位说明和填写示例，点开即可开始写。

### 2. 原生 Markdown 编辑体验
- 基于 Milkdown 引擎，所见即所得编辑
- 支持 GFM 扩展：表格、任务列表、删除线、代码块、引用
- **编辑 / 预览 / 双栏 / 源码** 四种模式一键切换
- Markdown 快捷语法：标题、加粗、斜体、链接、列表、引用
- 粘贴 HTML / Markdown 自动识别并格式化

### 3. 多端云同步
- 基于 Supabase，数据在云端实时同步
- 任意设备登录即可访问全部笔记
- 自动保存，跨设备无缝衔接

### 4. 目录 · 标签 · 收藏
- 支持多级目录（父子结构），按工作、生活、复盘等维度归类
- 自由打标签，并可按标签筛选
- 重要笔记加星标，在收藏列表里一眼找到

### 5. 日历视图
- 日历视图按日期浏览笔记
- 复盘 / 日计划 / 周计划模板与日历深度打通

### 6. 中英双语
- 中英文界面一键切换
- 模板与示例笔记均提供双语版本
- 适合跨境团队、英语学习、母语阅读等场景

### 7. 游客模式
- 无需注册即可体验全部模板与示例
- 注册后内容无缝迁移到个人账号

### 8. 搜索与筛选
- 顶部搜索框支持标题与正文模糊搜索
- 可按目录、标签、模板类型快速筛选

### 9. 回收站与恢复
- 误删的笔记可从回收站恢复
- 永久删除前二次确认，避免误操作

### 10. 主题与外观
- 两套主题风格：**极简** 与 **商务**
- 圆角卡片 + 柔和配色，长时间书写也舒适

## 适合谁用

- **产品 / 运营 / 设计师** —— 5W2H、同理心地图、RIDE、PREP 帮你把想法结构化
- **工程师 / 项目经理** —— 六顶思考帽、时间四象限、4D、GRAI 让协作更高效
- **学生 / 终身学习者** —— 康奈尔、SMART、WOOP 固化学习与目标管理
- **团队负责人** —— 月 / 周 / 日计划 + 复盘模板，把节奏稳稳握在手里

---

## 数据安全

- 笔记数据存放于 Supabase 托管的数据库
- 采用邮箱 + 密码登录，由 Supabase Auth 提供认证加固
- 回收站机制防止误删，关键操作需二次确认
